# Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify important trends, relationships, outliers, and business insights.

## Dataset

- 1000 records
- 11 columns
- Includes sales, profit, quantity, discount, region, category, product, and customer type.

## Analysis Performed

- Dataset inspection
- Missing value and duplicate checking
- Descriptive statistics
- Sales analysis by region, category, and product
- Profit analysis by category
- Customer type analysis
- Correlation analysis
- Outlier detection using IQR
- Box plot visualization
- Business questions and answers

## Key Findings

- West region generated the highest sales.
- Technology was the highest-selling category.
- Phone was the highest-selling product.
- Corporate customers generated the highest sales.
- Office Supplies generated the highest profit.
- Average sales per order: **2619.03**
